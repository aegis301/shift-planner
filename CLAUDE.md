# Claude Code entry point

Read these two files before doing anything in this repository:

1. `AGENTS.md` — architecture, conventions, and the standing rules under **Working an issue**.
2. `docs/rollout/STATE.md` — where the project stands, the roadmap, and the decisions that are
   already settled.

Both are authoritative. `docs/rollout/STATE.md` is a living file: update its **Status** and
**Roadmap** sections when work lands.
