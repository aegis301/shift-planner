# Decision records

Architecture and product decisions that shape more than one issue. Each record says what was
decided, why, what was rejected, and which issues carry it out. Records are append-only: a
decision that changes gets a new record that supersedes the old one, and the old one is marked
`Superseded by NNNN`.
